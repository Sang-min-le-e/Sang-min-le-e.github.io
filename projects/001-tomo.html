6인 팀에서 Flutter 앱 프론트엔드를 맡아, 팀의 Spring Boot 백엔드와 REST API로 연동했습니다. 로그인, 내 정보, 자녀, 루틴, 루틴 템플릿 API를 화면에 연결했고, 저장하면 관련된 화면(달력, 오늘 할 일, 홈)이 서버 데이터를 다시 불러오도록 Riverpod 상태 흐름을 설계했습니다.

02아키텍처

  2. Riverpod Actions

  4. Dio · REST API

03주요 기능

  • 로그인과 첫 로그인 3단계 설정(보호자, 자녀 정보)
  • 자녀 등록과 자녀별 루틴 관리
  • 루틴 달력, 추가, 수정, 삭제, 템플릿
  • 기기 연결을 위한 BLE 스캔 (연동 진행 중)
  • 프로필 사진, 회원 탈퇴
  • Figma 디자인을 기준으로 화면 구현
